# UX audit

This audit looks at the existing experience as a task: refill a prescription and know what it will cost.

## Findings

1. **Two homes for the same task.** Prescriptions appear on Home and on Pharmacy, with different organization. The member has to learn both.
2. **Action and content look alike.** Marketing and education sit in the same scroll as items that need a refill. There is no shared signal for “you can act on this.”
3. **Status is late.** Eligible, active, and already-submitted refills are not labeled the same way on every prescription.
4. **Cost is late.** The member price is not attached to the medication before the refill flow starts.
5. **The refill path is longer than the decision.** Choosing a pharmacy and a delivery method should not require a new hunt for the medication.

## Implications

Keep Home for orientation and questions. Put the prescription list, plan spending, status, and cost on Pharmacy. Make the refill button follow the status, so a medication that is not ready cannot be submitted by mistake.
