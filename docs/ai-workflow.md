# AI workflow

## Sydney in the product

Sydney is the member-facing assistant on Home. The card is labeled as an AI assistant so it is not mistaken for search or for a human inbox.

Sydney answers from the sample plan: what can be refilled, deductible and out-of-pocket remaining, and the latest claim. A question shows “Sydney is thinking,” then the reply. The suggestions are Refill status, Deductible, and Latest claim. The same questions can be typed.

The replies are scripted against the mock prescriptions, claims, and plan. They are there to show the interaction, not a live model.

## How this prototype was made

The screens were built in code with an AI coding assistant, then checked in the browser: sign-in, Sydney, pharmacy status, refill, loading, order confirmation, claims, settings, and logout.

Design changes stayed in the same repo as the prototype. The reference image set the visual direction. Later passes added the AI label and thinking state, Settings logout, the loading state before success, and the home-delivery fee.
